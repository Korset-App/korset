# 2026-05-09 — Чистый парсинг подкатегорий (Молоко, сливки, сгущённое молоко)

## Контекст задачи
Предыдущий метод сбора товаров основывался на поиске по 24 брендам и терминам через API Arbuz.kz. Это приводило к попаданию смежных товаров (сыры, творог, йогурты, масло, шоколад, детские смеси, мыло) в выборку «Молоко, сливки, сгущённое молоко». Требовалась 100% точная фильтрация для идеального соответствия подкатегории (около 247 уникальных товаров на сайте).

## Принятое решение
Перейти на гибридную архитектуру сбора данных:
1. **Каталожный парсинг (Phase 1)**: Прямая загрузка страниц `https://arbuz.kz/ru/almaty/catalog/cat/19986-moloko_slivki_sgush_nnoe_moloko?page={1..7}` и хирургическое извлечение ID товаров из Next.js-ссылок в HTML. Это дает **ровно 239 уникальных целевых продуктов** без примеси смежного мусора.
2. **API-обогащение (Phase 2)**: Использование детального эндпоинта `/shop/product/{productId}` для наполнения каждого товара КБЖУ, ингредиентами, условиями хранения, ценами и характеристиками.
