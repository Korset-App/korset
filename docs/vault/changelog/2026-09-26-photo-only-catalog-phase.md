# Фото-каталог: текущее рабочее состояние

- В рабочей базе 58 648 записей. В витрине активны 22 969, все со ссылкой на фото. 35 679 неактивны и сохранены для последующего разбора; из них 35 062 были активными без фото до этой операции, 617 колготок исключены ранее.
- Резервный список 35 062 изменённых EAN и прежних полей сохранён локально в `scratch/catalog-no-photo-archive-before.jsonl`; ход операции — в `scratch/catalog-no-photo-archive-progress.jsonl`. Записи и связи с магазинами не удалялись.
- MARS — единственный опубликованный магазин для работы над каталогом. Береке, Нұрлы и Калина временно сняты с публикации без удаления их данных. До отключения у них после фильтра оставалось соответственно 18, 7 и 4 видимых товара.
- Обновление `offlineDB` v5 удаляет устаревшую сохранённую копию каталога, сохраняя ожидающие сканирования. Следующее сохранение заменяет весь снимок товаров магазина, чтобы архивные строки не оставались в телефоне. Выпущено через GitHub → Vercel, коммит `6bc7b80`.
- Таблица `store_shopping_items` создана с RLS и четырьмя политиками доступа для собственного списка пользователя. Гостевая кнопка списка проверена в локальном браузере: нажатие меняет её состояние. Вошедший пользовательский сеанс не проверялся.
- В опубликованном MARS проверена молочная категория: 8 видимых карточек, 8 успешно загруженных изображений, ошибок JavaScript нет; версия локальной базы в браузере — 5. Проверка 8 карточек не доказывает доступность всех 22 969 внешних изображений.

Оставшиеся задачи: проверить качество и доступность изображений во всём активном наборе; исправить прочие ошибки категорий и потенциальные дубли по упаковке; наполнить состав и КБЖУ с доказанным происхождением каждого поля. Текущая постраничная загрузка показывает товары порциями и обновляет экран много раз: при 22 969 строках её архитектуру нужно отдельно оптимизировать по категориям и производительности.
