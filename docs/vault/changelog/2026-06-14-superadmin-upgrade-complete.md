# Релиз: Премиальное обновление панели супер-администратора (Super Admin Panel)

## Описание изменений
Глобальная панель супер-администратора (`/korset-admin/stores`) полностью переведена на профессиональный уровень B2B SaaS с интерактивной аналитикой активности, скрытым CRM-слоем и продвинутыми инструментами управления пользователями.

### 1. Базовая инфраструктура и БД
- Применена миграция `054_store_publication_and_metadata.sql`, добавившая колонки `is_published` (флаг публикации), `owner_private_phone` (секретный контакт владельца), `owner_private_notes` (заметки о сделке).
- Настроены строгие политики RLS: данные о неопубликованных магазинах и их товарах скрыты от анонимных пользователей и доступны только владельцу или супер-администраторам.
- Добавлен Vite-прокси на `/api` для бесшовной локальной разработки.

### 2. Серверные обработчики (`api/admin-stores.js`)
- Добавлен экшен `scan-activity` для агрегации сканов по дням за последние 14 дней.
- Добавлен экшен `search-owners` для живого поиска по учетным записям.
- Добавлен экшен `toggle-superadmin` для смены привилегий пользователя.
- Добавлен параметр `ownerId` в экшены `create` и `update-store-details` для гибкого связывания существующих аккаунтов.

### 3. Frontend UI (`SuperAdminStoresScreen.jsx` & `.css`)
- **Bento Dashboard:** Модульные KPI-карты (Всего магазинов, Общий ассортимент, Сканы, Ошибки EAN).
- **Интерактивный SVG-график:** Нативный линейный график с плавной анимацией и всплывающими тултипами при наведении на точки активности за 14 дней.
- **Sparklines:** Миниатюрные графики тренда сканов встроены в карточку каждого магазина.
- **Умный Drawer:**
  - Кнопки-акселераторы биллинга (`+1 мес.`, `+3 мес.`, `+6 мес.`, `+12 мес.`, `Бессрочно`) для управления сроком подписки.
  - Чекбокс `is_published` для перевода магазина в черновик.
  - Поля приватного телефона и заметок CRM (видны только суперадмину).
  - Управление владельцем: вкладки создания нового или выбора существующего пользователя из базы через живой поиск.
  - Переключатель прав суперадминистратора для владельца.
