Добавлены только фото исходных карточек Semeiniy с тем же EAN, только в пустое поле. 22 931 кандидат проверен локально; резервная копия прежних значений и прогресс находятся в `scratch/catalog-photo-sync-*.jsonl`. Выборочная ссылка ответила HTTP 200, а браузер загрузил фото в каталоге.

## Что ещё не решено

- Фото есть не у всех 58 648 строк: 35 679 без URL. Значительная часть — архивные, неподходящие или вне продуктового V1 ассортиментa; их статус пока не подтверждён.
- В предварительной группе активных пищевых товаров с фото сейчас 17 685 карточек, из них 9 835 с непустым составом. Это не оценка достоверности состава. КБЖУ в рабочей базе значительно меньше, чем в локальном файле; локальные данные нельзя массово переносить без проверки источника и соответствия упаковки.
- У финального V4 нет доказательства происхождения каждого поля: `prepare-master-v4-final.mjs` выставляет всем строкам `is_verified=true`, `source_confidence=95` и `source_primary=kz_verified` независимо от происхождения состава/КБЖУ. Повторная проверка OFF-выгрузок не нашла записей для массового безопасного переноса: одна даёт 0 новых полных наборов КБЖУ, другая — максимум 24 кандидата без сохранённого URL карточки.
- Проверка Playwright `catalogSearch.spec.js` не прошла: тест открывает `/s/demo-store`, а такого магазина сейчас нет. Сборка, тест загрузчика, локализация и проверка кода прошли.

Следующий приоритет: установить происхождение каждого состава и набора КБЖУ в локальном V4; перенести только поля с доказанным соответствием EAN/упаковки, затем отдельно добывать недостающие данные с оборотных фото или подтверждённых карточек производителя.
