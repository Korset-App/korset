Пользователь провёл домашний тест: отсканировал камерой смартфона реальные продукты из кухни/холодильника (Raffaello, майонез, кофе).
- **Результаты теста**:
  - Товар либо не находился.
  - Либо открывался другой товар того же бренда:
    - При сканировании коробки конфет Raffaello (200 г) открылась карточка конфет Raffaello (40 г).
    - При сканировании майонеза открылось другое ведро / другой объём майонеза.
    - При сканировании кофе одного вкуса открылся другой вкус.

То есть на уровне записей в базе товары **не склеены**.

## 5. Почему после правок проблема могла сохраниться (гипотезы для нового чата)
1. **PWA Service Worker / Cache Storage**:
   - Мобильный Chrome/Firefox при установленном PWA или зарегистрированном Service Worker продолжает отдавать старый бандл JS из `CacheStorage`, пока воркер не обновится в фоне и страница не перезагрузится дважды. Обычная очистка кэша в настройках браузера иногда оставляет Service Worker активным для PWA.
2. **Ошибки считывания камеры (ZXing Barcode Scanner)**:
   - На глянцевых упаковках (фольга Raffaello, круглые пластиковые вёдра майонеза) камера может ловить блики и декодировать контрольную сумму с ошибкой, либо считывать с упаковки другой технологический штрихкод (например, код коробки / паллеты или вспомогательный UPC).
   - В текущем UI сканера нет визуального отображения: **какие именно 13 цифр только что распознала камера**. Из-за этого пользователь не видит, какую строку цифр передал сканер.
3. **Каталог магазина (`store_catalog` sync)**:
   - В магазине MARS синхронизированы не все 11 000 товаров, а только часть. Если сканируется штрихкод, которого нет в `store_products`, но он есть в `global_products`, как именно отрабатывает логика?
   - В `findProductInCatalog` проверяется `alternate_eans`. Если в закешированном массиве всё ещё сидит старая запись, поиск отдаёт первое совпадение.

4. **Шаг 4: Тест в режиме Инкогнито / Без Service Worker**:
   - Попросить пользователя открыть прямую ссылку в режиме Инкогнито: `https://korset.kz/s/mars/scan?nocache=1`. В Инкогнито Service Worker не кэширует код, и запросы идут 100% чистыми.
5. **Шаг 5: Вывести распознанные цифры EAN на экран**:
   - Всплывающее уведомление (toast) на экране сканера: *"Распознан штрихкод: 4607086410240"*, чтобы пользователь сразу видел, что именно прочитала камера.
