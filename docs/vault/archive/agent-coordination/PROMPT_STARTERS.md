# KORSET — PROMPT STARTERS

> Короткие старты для владельца проекта. Можно вставлять в Codex, OpenCode, Windsurf, Antigravity.
> Пиши только тему после двоеточия — агент должен сам применить `AGENTS.md`, `docs/CONTEXT.md` и нужный task mode.
> Инструменты подбираются по `docs/AI_TOOLS_MATRIX.md`.

---

## UI Task

```text
UI-задача: [что меняем]

Работай по AGENTS.md и docs/AI_TASK_MODES.md в UI Mode.
Сначала быстро проверь текущий экран/компоненты/стили/i18n/роуты.
Если изменение затрагивает дизайн-направление или спорные UX-решения — сначала предложи план и вопросы.
Если всё очевидно — реализуй, проверь и обнови память только при значимом изменении.
```

## Bugfix

```text
Багфикс: [что сломано / что вижу]

Работай по Bugfix Mode.
Сначала локализуй причину по коду и проверкам, не переписывай соседние части.
Если причина спорная или данных не хватает — остановись и задай короткий вопрос.
После фикса запусти релевантную проверку и скажи, что именно проверено.
```

## Supabase / DB

```text
Supabase-задача: [что нужно сделать]

Работай по Supabase / DB Mode.
Проверь схему, RLS, миграции, JS-consumers и безопасность.
Не меняй production data и не ослабляй RLS без явного подтверждения.
Сначала дай план, если есть риск для данных/auth/security.
```

## Architecture

```text
Архитектурная задача: [тема]

Работай по Architecture Mode.
Сверь docs/CONTEXT.md, docs/ARCHITECTURE.md, релевантный Vault и реальный код.
Не верь старым документам без проверки.
Дай честный вывод, варианты и рекомендуемое решение.
```

## Memory / Docs

```text
Memory-задача: [что нормализуем]

Работай по Memory Mode.
Не раздувай AGENTS.md и CONTEXT.md.
Детали переноси в Vault, быстрые выводы оставляй в CONTEXT, долгую архитектуру — в ARCHITECTURE.
После значимых Vault-изменений запусти npm run memory:save.
```

## Multi-Agent Handoff

```text
Handoff: [что передать другому агенту]

Сделай короткий handoff:
- цель;
- что уже сделано;
- изменённые файлы;
- write-zone;
- что нельзя трогать;
- проверки;
- риски;
- следующий шаг.
```
