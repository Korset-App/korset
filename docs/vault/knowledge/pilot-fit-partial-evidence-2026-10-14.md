# Проверка товара при частичных сведениях

П08/П09 требуют сохранения известного ограничения и осторожного итога при недостатке фактов. Первые 28 браузерных случаев подтвердили существующие сочетания: безлактозность/молочный белок, следы, противоречащие составу теги, неизвестный состав для keto/веганства. Приложение для них менять не требовалось.

Обнаружен отдельный дефект: наличие любого структурированного аллергена или следов считалось достаточным основанием для фразы «Не содержит ваших аллергенов», даже без состава. Два модульных и восемь браузерных отказов воспроизвели неверное «подходит» при постороннем глютене/следах рыбы для профиля с молоком. Логи `../fit-safety-partial-unit-red-20261014.log`, `../fit-safety-partial-red-20261014.log`.

Независимый разбор выявил связанные случаи: строка только о следах и посторонний аллерген для проверки целиакии. Отдельное выполнение действующей функции и новые модульные случаи подтвердили ложный безопасный итог: `../fit-safety-review-repro-20261014.log`, `../fit-safety-review-unit-red-20261014.log`.

В `fitCheck.js` подтверждение отсутствия аллергена теперь требует основной части состава, отделённой существующим разборщиком от оговорок о следах. Недостаток состава для пищевых/медицинских предпочтений использует тот же признак; произвольный список аллергенов больше не заменяет состав для проверки целиакии. Прямое совпадение аллергена и релевантные следы вычисляются раньше и сохраняют запрет/предупреждение. Пищевые пороги, исходные данные, схема и источники не менялись.

Три прежние проверки безопасного результата дополнены явным составом: посторонний аллерген/следы остаются совместимыми с конкретным профилем при наличии остальных оснований. Добавлены пять случаев частичных сведений, включая текст только о следах и неизвестность для веганства. Это уточнение доказательств прежних положительных тестов, а не удаление проверки успеха.

## Фактические результаты

- `tests/pilot/fitSafety.spec.js`: 44 случая — 11 сочетаний, RU/KZ, обе темы. Проверены результат каталога, результат карточки и раскрытая причина. Отдельный положительный случай без аллергии подтверждает, что безлактозное предпочтение не превращено в запрет.
- Совместно с прежним покупательским набором 49/49, `../fit-safety-final-browser-20261014.log`.
- `check:agent:full`: 968/968 модульных, переводы/код/сборка и одна проверка установленного приложения без сети прошли. Лог `../fit-safety-final-full-20261014.log`.
- Адресный ESLint обоих тестов и проверка различий прошли. Независимый повторный разбор финальных изменений конкретной регрессии не нашёл; проверяющий тесты не запускал.

Используется прежняя тестовая строка `UNKNOWN_EAN`; варианты состава/тегов — синтетические проверки правил, не обновления реального товара. Ответы магазина и профиль подменены, внешние запросы запрещены. Это не медицинская или юридическая проверка правил и не приёмка упаковок настоящего магазина. База, физическая камера, исходная папка, публикация и Antigravity не затронуты.

Следующий независимый участок — кабинет: сохранённый статический отчёт `scratch/overnight-retail-review-2026-10-14/report.md` описывает неизвестное наличие как включённый переключатель, который записывает отсутствие. Сначала сверить текущий код и границы Antigravity, затем воспроизвести только на подменённых ответах. Витрину/настройки не менять. Реальные этикетки, телефоны и доступ UMAG остаются отдельными условиями пилота.
