# Карточка учётного товара при потере сети

## Подтверждённый пробел П12

Существующие проверки покрывали осторожность неизвестного состава при потере сети, повторную отправку фотографии и изоляцию точек. Они не покрывали свежую открытую карточку учётного товара с активной скидкой. Текущий экран обновлял такую карточку раз в минуту и не реагировал на восстановление сети.

В локальном браузере воспроизведено: при обрыве сети открытая карточка продолжает сообщать «Есть в наличии» и показывать акционную ставку 800 ₸/кг вместо сохранённой обычной 1 000 ₸/кг; восстановление соединения не вызывает нового подтверждения. Первое воспроизведение русской подписи содержало ошибку теста; после сверки точного существующего текста отдельный прогон подтвердил отсутствие ожидаемого неизвестного наличия. Доказательства: `source-offline-transition-red-20261014.log`, `source-offline-red-20261014.log` рядом с копией.

## Изменение

`StoreSourceProductScreen` использует существующий контекст сети. Потеря соединения сразу применяет существующий безопасный запасной путь: обычная сохранённая цена, неизвестное наличие, отсутствующая акция. Запросы и минутный опрос останавливаются, прежний ответ помечается неподтверждённым. После восстановления экран запрашивает данные заново; пока ответ не подтверждён, сохранённые сведения остаются явно неподтверждёнными. Отмена запроса при уходе/обрыве не позволяет позднему ответу подтвердить старую карточку.

Ошибка нового запроса сохраняет уже загруженную карточку этой же точки и ссылки, если её нет в каталоге. Подтверждённый пустой ответ сохраняет прежний смысл «товар недоступен»; это не смешивается с отказом сети. Ветка другой точки не получает прежний товар. Единицы, внутренний идентификатор без заводского штрихкода, возможность добавить в список и неполнота состава сохранены.

Новая подпись RU/KZ говорит именно о сохранённых данных и необходимости уточнить текущую цену/наличие. Недавний отказ сети не называется давним обновлением. Прежняя подпись устаревшего наблюдения остаётся для случая с подтверждённым старым временем.
