# Исследование и аудит источников данных продуктов и штрих-кодов в Казахстане

**Дата:** 2026-09-19  
**Область:** Data Engineering / EAN Harvest / Product Catalog  
**Статус:** Актуальный аудит

---

## 1. Контекст задачи

Для масштабирования каталога Körset (офлайн-магазины Казахстана) критически необходимы:
1. **Точные штрих-коды (EAN-13)** производителя (не внутренние артикулы магазинов).
2. **Качественные фотографии пачек** с высоким разрешением на белом/прозрачном фоне.
3. **Чистые составы и КБЖУ** (для Fit-Check, аллергенов, кето и халал-проверки).

Ниже приведен детальный технический аудит всех доступных источников данных в Казахстане и мире.

## 2. Анализ источников в Казахстане

### 2.1. Национальный каталог товаров РК (НКТ — nationalcatalog.kz / nct.kz)
* **Статус в Körset:** Частично интегрирован в скриптах (`scripts/arbuz-import.cjs`, `scripts/resolve-v3.cjs`).
* **Что содержит:** Официальные GTIN/NTIN коды Республики Казахстан, зарегистрированные производителями и импортерами в системе маркировки и GS1.
* **Наличие EAN-13:** 100% (GTIN-13).
* **Качество данных:**
  - Названия и бренды — официальные, высокая достоверность.
  - Составы и КБЖУ — заполняются производителями через ЭСФ/СНТ, часто неполные или в сыром виде.
  - Фотографии — низкого разрешения либо отсутствуют.
* **Технический доступ:**
  - Имеется Open API: `https://nationalcatalog.kz/gw/search/api/v1/search` (требуется `X-API-KEY`).
  - С сентября 2026 года ужесточена авторизация через ЭЦП для личных кабинетов, но поисковый шлюз доступен для валидации.
* **Вердикт:** **Главный источник верификации EAN-13** для казахстанских товаров. Незаменим для проверки подлинности штрих-кода, но требует дополнения фотографиями из других баз.

---

### 2.2. Arbuz.kz
* **Статус в Körset:** Основной источник первичного импорта (~5 000+ товаров).
* **Что содержит:** Бакалея, молочка, напитки, сладости, органика, бытовые товары.
* **Наличие EAN-13:** Присутствует в скрытых полях карточки товара или через сопоставление по API (`https://arbuz.kz/api/`).
* **Качество данных:**
  - Фотографии — эталонные, студийные, без водяных знаков.
  - Составы — на русском языке, хорошая структурированность.
* **Потенциал расширения:**
  - В проекте были спарсены ~25 подкатегорий. Остались нетронутыми категории свежих полуфабрикатов, национальных продуктов (курт, шубат, казы), детского питания и снеков.
* **Вердикт:** **Лучший источник студийных фото и описаний в РК**.

---

### 2.3. Magnum.kz / Magnum Go (Мобильное приложение)
* **Особенности:**
  - Web-сайт magnum.kz не содержит открытого сквозного каталога штрих-кодов.
  - Мобильное приложение использует закрытый GraphQL/REST бэкенд с токенизацией сессий.
  - **Критический нюанс:** В каталоге и поиске Magnum отображает внутренний артикул сети (SKU), а не EAN-13 производителя! EAN-13 проверяется на бэкенде только при сканировании штрих-кода камерой внутри магазина.
* **Защита:** Защита мобильного API через проверку подписи запросов и Cloudflare на веб-зеркалах.
* **Вердикт:** Сложный реверс-инжиниринг с высоким риском бана IP и нестабильным извлечением EAN-13. Не рекомендуется для первичного сбора.

---

### 2.4. Small.kz / Small Food
* **Особенности:** Каталог доступен через мобильное приложение Small Food. На сайте штрих-коды не индексируются поисковиками.
* **Вердикт:** Идентично Magnum — закрытый мобильный каталог с внутренними артикулами.

---

### 2.5. Kaspi.kz (Магазин / Продукты питания)
* **Особенности:**
  - Огромная база продуктов питания от сотен мерчантов.
  - **Защита:** Akamai Bot Manager, блокирующий любые автоматические запросы headless-браузеров (Playwright/Puppeteer) или скриптов через капчи.
  - **Проблема со штрих-кодами:** В карточках Kaspi EAN-13 скрыт от публичного просмотра. Используется собственный `Master Product ID` / `modelId`.
* **Вердикт:** Низкая рентабельность парсинга из-за жесткой защиты и отсутствия открытых EAN-13.

---

### 2.6. Galmart.kz и Carefood.kz
* **Особенности:** Премиальные супермаркеты (Астана/Алматы).
* **Каталог:** Работает на стандартных CMS (Битрикс/WooCommerce).
* **Наличие EAN-13:** В большинстве карточек штрих-код отсутствует в DOM, отображается только номенклатурный код 1С.
* **Вердикт:** Можно использовать как источник названий редких импортных товаров, но не для прямого извлечения EAN.

---

## 3. Международные открытые базы с поддержкой Казахстана

### 3.1. Open Food Facts (OFF — world.openfoodfacts.org)
* **Что содержит:** Более 3 000 000 товаров по всему миру.
* **Казахстанский сегмент:** Несколько десятков тысяч товаров с префиксами 487 (Казахстан), 460-469 (РФ), 481 (Беларусь) и импорта.
* **Доступность:**
  - 100% бесплатный Open API (`https://world.openfoodfacts.org/api/v2/product/{barcode}`).
  - Ежедневные полные дампы в формате `jsonl.gz` и `parquet`.
  - Отсутствие капч и банов при соблюдении User-Agent.
* **Что есть в записи:**
  - EAN-13 (ключ `code`).
  - Фото упаковки (лицевая сторона, состав, таблица КБЖУ).
  - Распознанный текст ингредиентов.
  - Теги Halal / Vegan / Vegetarian / Nutri-Score.
* **Вердикт:** **Идеальный источник для обогащения (Enrichment)**. Можно локально скачать выборку по префиксам `487*` и `460*` без единого платного API-запроса!

---

### 3.2. BarcodeSpider / EAN-Search / GS1 Cloud
* Специализированные сервисы для распознавания штрих-кодов импортной продукции (Coca-Cola, Nestle, Unilever, Ferrero, Mars, Danone).
* Имеют бесплатные лимиты (100–500 запросов/день).
