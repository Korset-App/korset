## 1. ПОЧЕМУ НУЖЕН ПОЛНЫЙ РЕБИЛД

Текущий лендинг (V2) — это **улучшенная версия старого дизайна**, а не новый лендинг. Проблемы:

1. **Визуально похож на старый** — те же иконки+текст карточки, те же короткие секции
2. **Слишком мало контента** — секции короткие, по 2-3 строки текста
3. **Почти нет изображений** — только CSS phone mockup + градиентные placeholder'ы. Нет фото продуктов, людей, скриншотов
4. **Секции слишком короткие** — каждая занимает минимум вертикали, нет ощущения «богатого» лендинга
5. **Не соответствует референсам** — Shopify/Framer/Linear имеют длинные, насыщенные секции с крупными изображениями, детальными мокапами продукта, обильным текстом

**Цель:** Полностью переписать лендинг, визуально максимально приближаясь к Shopify.com (главный референс), с элементами Framer и Linear.

## 3. ТЕХНИЧЕСКИЙ СТЕК И ОГРАНИЧЕНИЯ

### Стек (ЖЕЛЕЗНО — не менять):
- **React 18** + **Vite**
- **JavaScript** (НЕ TypeScript)
- **Vanilla CSS** (НЕ Tailwind, НЕ CSS-in-JS, НЕ styled-components)
- **i18n:** `useI18n()` хук — ВСЕ тексты через `t('key')` с RU + KZ
- **Шрифты:** Advent Pro (display/headings), Inter (body)
- **Акцент:** `#7c3aed` (purple), sky: `#38bdf8`
- **Тёмная тема только** — лендинг работает ТОЛЬКО в тёмной теме
- **CSS-переменные** — использовать только `var(--text)`, `var(--bg-app)`, `var(--primary)`, `var(--glass-bg)`, `var(--glass-border)` и т.д. из `src/index.css`. **НЕ хардкодить** `#fff`, `#000`, `rgba(255,255,255,...)` для текста/фона/бордеров

### Адаптивность (обязательно):
- **6 breakpoints:** 360 / 480 / 768 / 1024 / 1280 / 1440
- **clamp()** для всех ключевых размеров
- **`@media (hover: hover)`** — hover-эффекты только на мышке
- **Height queries** — компактный hero на landscape (≤680px)
- **Safe-area** — `env(safe-area-inset-*)`
- **prefers-reduced-motion** — отключать анимации
- **focus-visible** — accessibility outlines
- **Mobile-first** — все стили пишутся от маленького к большому

### Файлы:
- `src/screens/LandingScreen.jsx` — компонент
- `src/screens/LandingScreen.css` — стили (ПОЛНОСТЬЮ переписать)
- `src/locales/ru/home.json` — RU ключи
- `src/locales/kz/home.json` — KZ ключи
- `public/landing/` — папка для изображений (создать если нет)

## 4. ИЗОБРАЖЕНИЯ-ЗАГЛУШКИ

### Подход: Unsplash/Pexels placeholder'ы

Использовать реальные фото из Unsplash как заглушки. **НЕ gradient boxes, НЕ иконки в кружках.** Каждая секция должна иметь крупное, заметное изображение.

**Как вставлять:** Использовать прямые ссылки Unsplash (формат `https://images.unsplash.com/photo-XXXX?w=800&q=80`) или скачать в `public/landing/`. Прямые ссылки проще для первого прохода — заменим на локальные файлы позже.

**Обязательные изображения:**

| Секция | Что на фото | Пример поиска Unsplash |

| How (шаг 1) | Человек у полки с телефоном | `person shopping phone`, `qr code scanning` |

## 10. CSS — ПРАВИЛА

1. **Только CSS-переменные** для цветов: `var(--text)`, `var(--bg-app)`, `var(--primary)`, `var(--glass-bg)`, `var(--glass-border)` и т.д.
2. **НЕ хардкодить** `#fff`, `#000`, `rgba(255,255,255,...)` для текста/фона/бордеров
3. **Полупрозрачные акцентные цвета** (фиолет/красный/зелёный для статусов) — допустимы как `rgba(...)`, они работают в обеих темах
4. **Локальные переменные** `--lp-*` — использовать для секционных значений
5. **clamp()** для всех ключевых размеров
6. **Mobile-first** — стили от маленького к большому
7. **6 breakpoints:** 360 / 480 / 768 / 1024 / 1280 / 1440
8. **`@media (hover: hover)`** — hover только на мышке
9. **prefers-reduced-motion** — отключать transform transitions + scroll-behavior
10. **focus-visible** — accessibility outlines
11. **Height queries** — компактный hero на landscape (≤680px)
12. **Safe-area** — `env(safe-area-inset-*)`
13. **scroll-behavior: smooth** + **scroll-padding-top**
14. **overscroll-behavior: contain**
