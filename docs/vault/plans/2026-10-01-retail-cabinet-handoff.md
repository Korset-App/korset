## 1. О продукте и бизнес-контексте

* **Körset** — мобильно-ориентированный B2B2C веб-сервис (PWA) для оффлайн продуктовых магазинов и супермаркетов Казахстана.
* **Покупатель** сканирует штрихкод (EAN-13 / EAN-8) товара в конкретном магазине (`/s/:storeSlug`) и получает Fit-Check: состав, аллергены, халал-статус, диабетический статус, КБЖУ.
* **Магазин (Ритейл)** оплачивает SaaS-подписку за витрину, аналитику сканирований, выявление упущенного спроса и синхронизацию каталога (1С).
* **Retail Cabinet** (`/retail/:storeSlug/*`) — это рабочий кабинет управляющего/директора магазина.

## 2. Ключевые требования пользователя и зафиксированные решения

### Чего категорически НЕ должно быть (антипаттерны):
1. **Никаких дешёвых псевдо-логотипов:** Запрещено использовать синие квадратики с буквой «К» или любительские заглушки. Используется только официальный изометрический 3D-кристалл `KorsetBrandMark.jsx` (грань `#A087FF` и белые фасеты из `public/brand/korset-icon.svg`).
2. **Никакого дублирования сущностей:** Раньше в сайдбаре сверху была карточка «Магазин» с буквой «К», а снизу ещё одна карточка «Управляющий» с буквой «К». Это путало. Контекст магазина и профиль управляющего должны быть строго разделены.
3. **Никакого визуального мусора в постоянном меню:** В боковой панели не должны постоянно висеть растянутые кнопки RU/KZ, кнопка темы, кнопка «Установить на ПК» и ссылки на витрину. Пользователь не меняет тему и язык каждую минуту.
4. **Никаких бутафорских заглушек аккаунта:** В сайдбаре внизу не должно быть просто надписи «Управляющий» с буквой «У» без функционала. Должно быть полноценное модальное окно управления аккаунтом.
5. **Единый стиль контролов:** Переключатели языка и темы должны использовать официальный проектный компонент `SegmentedToggle.jsx` с пружинной GPU-анимацией скольжения (`spring cubic-bezier`), а не разношёрстные кнопки.

### Что должно быть и как реализовано:
1. **Левая боковая навигация (`RetailDesktopSidebar.jsx`):**
   * Ширина 260px (в свернутом виде — 72px без рывков и наползания текстов).
   * Верх: Официальный знак `KorsetBrandMark` + «Körset» + сдержанный бейдж «RETAIL» + кнопка сворачивания (шевронка).
   * Чуть ниже: Единый чип магазина (Store Context) — логотип магазина (или монограмма из `<ProfileAvatar />`), статус («В сети» / «Черновик») и slug магазина.
   * Центр: 5 основных разделов кабинета:
     1. **Обзор** (`/retail/:storeSlug/dashboard`) — Bento-сетка KPI, упущенная выручка, топ сканирований, ИИ-рекомендации.
     2. **Каталог** (`/retail/:storeSlug/products`) — таблица товаров, поиск, фильтры, статус штрихкодов.
     3. **Витрина** (`/retail/:storeSlug/storefront`) — загрузка и кадрирование логотипа (`ImageCropModal`), фото магазина, печать А4 QR на кассу, живой превью-смартфон (`StoreLivePreviewCard`).
     4. **Синхронизация** (`/retail/:storeSlug/integration`) — подключение 1С и учётных систем.
     5. **Настройки** (`/retail/:storeSlug/settings`) — 9 якорных секций (контакты, расписание, ИИ-новости, опасная зона).
   * Низ (Футер): Единственная карточка управляющего с аватаром. При клике открывается всплывающее меню (Popover):
     * Имя, Email, роль.
     * Кнопка **«Управление аккаунтом»** (открывает `RetailAccountModal`).
     * Тумблер темы через `SegmentedToggle` (Солнце ☀️ / Луна 🌙).
     * Тумблер языка через `SegmentedToggle` (RU / KZ).
     * Кнопка установки на ПК (если браузер поддерживает PWA).
     * Служба заботы в Telegram (`@korset_support_bot`).
     * Выход из аккаунта (`signOut`).
2. **Модальное окно профиля управляющего (`RetailAccountModal.jsx`):**
   * Выбор аватара из официальных коллекций (`AVATAR_PRESETS` и `SILHOUETTE_PRESETS`) с живой примеркой.
   * Редактирование имени управляющего.
   * Смена пароля (новый пароль, подтверждение, валидация длины от 6 символов).
   * Прямое сохранение через `supabase.auth.updateUser`.
3. **Верхняя панель (`RetailDesktopTopbar.jsx`):**
   * Хлебные крошки (`Магазин / Раздел`) + статус магазина.
   * Быстрое копирование ссылки на витрину (`ShareIcon` + toast).
   * Кнопка открытия витрины в новой вкладке (`EyeIcon` + «Витрина» + `ExternalLinkIcon`).
   * Кнопка «Установить на ПК» (если доступен PWA prompt).
   * Меню быстрых действий (Печать QR на кассу, Вход со смартфона по QR).
4. **Экран авторизации ритейла (`RetailAuthScreen.jsx`):**
   * Маршрут `/retail/login`.
   * Брендовый кристалл `KorsetBrandMark`, вход по паролю и по 6-значному OTP-коду на почту, переключение языка и темы, редирект `returnTo`.

## 3. Технический стек и правила (Stack & Invariants)

* **Фреймворк:** React 18 + Vite (SPA).
* **Язык:** JavaScript (JSX), **строго НЕ TypeScript**.
* **Стилизация:** Чистый CSS (`RetailLayout.css`), **строго НЕ Tailwind**. Использование существующих CSS-переменных (`--retail-bg`, `--retail-header-bg`, `--retail-border`, `--retail-accent`, `--text`, `--glass-bg`).
* **Бэкенд:** Supabase (Auth, Postgres, Storage, RLS).
* **Локализация:** `useI18n` с обязательным 100% покрытием RU и KZ (`node scripts/check-i18n.mjs`).
* **Иконки:** Курированные SVG из `src/components/icons/index.js`.
* **Тесты:** `npm run test:unit` (807 тестов должны проходить с 0 ошибок).
