## Контекст и цель

База: 58 648 товаров, из них ~23 947 активных.  
Проблемы, выявленные пользователем:

1. **Нейминг** — несогласованный стиль: где-то вес в названии, где-то бренд продублирован, торговые аббревиатуры (м/у, к/у, пэт, ст/б...), разные форматы веса (100гр, 100Г, 100 г, 100 мл).
2. **Description vs Ingredients** — во многих карточках состав попал в поле `description`, а `ingredients_raw` пустое (и наоборот).
3. **name_kz** — казахских названий нет. Нужен перевод.
4. **Внутренние данные** — состав (ingredients_raw) иногда содержит маркетинговый текст.

**Приоритет ночи:** только **активные** товары (~23 947). Архивные — отдельная сессия.

---

## Архитектурное решение: per-field passes, не per-product

**Почему не per-product (всё сразу на одну карточку):**
- 23 947 карточек × ~4 поля = ~96 000 AI-вызовов → дорого и медленно
- Один косяк в промпте портит все поля сразу
- Сложнее откатить частичный прогон

**Почему per-field pass лучше:**
- Каждый пас — одна цель, один риск, один откат
- Бо́льшую часть нейминга можно сделать **без AI** (regex/правила) — быстро и бесплатно
- AI-вызовы только там, где правила не справятся

## Фазы (по порядку запуска)

### Фаза 1 — Rule-based name cleaning (БЕЗ AI) — ✅ ВЫПОЛНЕНО (30.09.2026)

**Скрипт:** `scratch/normalize-names-rules.mjs`
**Итоги:** 23 947 активных проверено, 22 233 (93%) нормализовано и записано в Supabase, 1 712 без изменений, 2 пропущено (<4 симв), 0 ошибок.
**Время выполнения:** ~12 мин
**Лог аудита:** `scratch/normalize-log-2026-09-29.jsonl`

**Правила (применять в порядке):**

```
1. Убрать торговые форматы-суффиксы:
   - /\s+[мМ][/][уУ]\b/g (м/у)  
   - /\s+[кК][/][уУ]\b/g (к/у)  
   - /\s+д[/]п\b/gi (д/п)  
   - /\s+т[/]п\b/gi (т/п)
   - /\s+пэт\b/gi
   - /\s+ст[/]б\b/gi (ст/б)
   - /\s+ж[/]б\b/gi (ж/б)
   - /\s+пауч\b/gi
   - /\s+ведро\b/gi
   - /\s+шоубокс\b/gi
   - /\s+флоу-пак\b/gi

2. Нормализовать формат веса:
   - /(\d+)\s*[гГ][рР]\b/ → "$1г"
   - /(\d+)\s*[гГ]\b/ → "$1г"  
   - /(\d+)\s*[мМ][лЛ]\b/ → "$1мл"
   - /(\d+)\s*[кК][гГ]\b/ → "$1кг"
   - /(\d+)\s*[лЛ]\b(?!\w)/ → "$1л"

3. Убрать двойные пробелы, trim

4. Sentence case (первая буква заглавная, остальное как есть — бренды и аббр. не трогать)

5. Убрать дублирование бренда в начале названия ТОЛЬКО если:
   - brand != null
   - название начинается точно с бренда + пробел
   - после удаления остаётся >= 3 символов
```

**Что НЕ делать в Фазе 1:**
- Не трогать `brand`, `description`, `ingredients_raw`
- Не изменять имена, если `specs_json.name_normalized = true`

### Фаза 2 — Description / Ingredients swap detection (AI) ← **после ночи, с проверкой**

**Скрипт:** `scratch/fix-desc-ingredients-swap.mjs`  
**Размер:** только товары где `description != null AND ingredients_raw != null`, оба длиннее 50 символов  
**Оценочно:** ~3 000–5 000 записей  
**AI:** GPT-4o-mini, по 20 записей в батче, classify only (no rewrite)

**Задача AI:** определить, не перепутаны ли поля:
```json
{ "action": "swap" | "ok" | "skip" }
```
Если `swap` — поменять местами описание и состав. Если `skip` — описание подозрительно, не трогать.
