## 2. Задачи для следующей сессии

### Задача А: Дообогащение описаний (`description`)
- **Текущее состояние:** 5 553 товара без детального описания (у 5 830 товаров описания уже есть).
- **План действий:**
  1. Пакетная генерация описаний через AI (короткие, понятные покупателю тексты по 1–2 предложения, описывающие вкус, назначение и особенности продукта).
  2. Запуск локальным скриптом с ограничением параллельности.

### Задача Б: Дообогащение составов (`ingredients_raw`)
- **Текущее состояние:** 2 393 товара без полного состава.
- **План действий:**
  1. Запрещено выдумывать составы через нейросеть — только реальные источники с упаковок.
  2. Подключить дополнительные открытые базы по штрихкодам или краулер локальных сетей (Small, Ayan, Magnum).
  3. Для ГОСТовских мясных консервов (ГОСТ 32125-2013) и моно-продуктов применить строгий нормализатор составов.

### Задача В: Способы приготовления (`cooking_instructions`)
- **Текущее состояние:** 1 276 товаров имеют инструкции (пельмени, каши, крупы, макароны, лапша, кофе, чай).
- **План действий:**
  - Расширить покрытие на соусы, замороженные полуфабрикаты (блинчики, наггетсы, тесто, пицца).

### Задача Г: Масштабирование каталога (11 000 → 15 000+ SKU)
- **План действий:**
  1. Выгрузка новых категорий товаров повседневного спроса.
  2. Валидация Luhn mod-10 и GS1-префиксов через `scripts/utils/ean-validator.mjs`.
  3. Пакетный перевод `name_kz` и халяль-верификация.
  4. Синхронизация в `clean_products_v2`, `global_products` и витрины 4 магазинов.
