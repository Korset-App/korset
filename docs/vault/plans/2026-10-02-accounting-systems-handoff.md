# Учётные системы: сохранение работы и следующий шаг

## Решения владельца и проверенные сведения

Опрос владельца Körset: 10 потенциальных магазинов, UMAG — 6, 1С — 1,
2X POS — 2, Wipon — 1. Это выборка клиентов, не доли рынка Казахстана.
Точное название, поставщика и версию 2X POS ещё подтвердить; не подменять другой системой.

Цель неизменна: ассортимент, цены и наличие автоматически обновляются в Körset
после изменений в учётной системе, без двойного ручного ведения.
Регулярная ручная загрузка таблиц не удовлетворяет этой цели. Автоматическая
выгрузка файлов может быть вариантом только при поддержке источником и проверке
полноты, актуальности, повторной доставки и безопасного доступа.

Владелец просит экономить токены, сохранить 1С и общую основу обмена.
Сегодня выполняется сохранение и передача контекста, без доработки коннектора.
1С остаётся востребованной интеграцией; прежнюю работу не удалять и не переписывать.
UMAG — первый кандидат для проверки условий подключения по результатам этой выборки.
Реализация новых подключений, смена архитектуры и изменения рабочей базы не согласованы.

Согласившийся магазин есть в другом городе; владелец ожидает возможность визита
через 4–5 дней (ориентировочно 6–7 октября 2026). Владелец подтвердил: система UMAG.
Не планировать установку до проверки доступа, совместимости и согласия магазина.

Общую основу рассматривать для повторного использования: приём пакетов,
проверка штрихкодов, сопоставление товаров, повторы, полная сверка и диагностика.
Пригодность для каждой системы проверить по её контракту; не обещать полную
совместимость и не запускать миграции заново по этой передаче.

## Уточнение владельца: исследование без переговоров

Владелец отклонил обращения к поставщикам и партнёрские переговоры как первый
шаг. Не отправлять сообщения и не строить план на ожидании ответов поддержки.
Сначала самостоятельно проверять публичные документы, пробные версии, настройки
разрешённого кабинета, выгрузки и доступные способы автоматизации. Владелец
разрешил двух ограниченных помощников Luna / low (экономная модель / небольшой
объём рассуждений) для поиска; основная модель проверяет выводы. Это разрешение
на исследование, не на изменения учётных систем или рабочей базы Körset.

## Результаты проверки 02.10.2026

### UMAG

- [Инструкция склада](https://umag.kz/razdel/sklad) подтверждает ручную выгрузку
  списка в XLSX (таблицу Excel): раздел «Склад» → «Скачать». Описаны название,
  штрихкод, дополнительный код, количество, закупочная/продажная цены и суммы.
  Можно включать нулевые остатки и фильтровать заводские/весовые/внутренние коды.
  Точные заголовки/типы колонок и идентификатор точки проверить на реальном файле.
- [Расширения](https://umag.kz/razdel/rasshireniya) существуют, но эта инструкция
  не раскрывает универсальный доступ сторонней программы к каталогу.
- [Приложение разработчика](https://play.google.com/store/apps/details?id=kz.umag.android)
  скачиваемое, однако предназначено для пользователей UMAG; это не подтверждение
  бесплатной пробной базы. Установка приложения сама не даёт доступ к данным.
- Живая страница `https://admin.umag.kz/auth` проверена браузером: телефон, пароль,
  восстановление пароля. Гостевой вход или регистрация на этой странице не обнаружены.
  В интерфейсе есть обозначение версии API, но это не документация внешнего обмена.
- Публичный API (программный интерфейс обмена), выдача внешнего ключа, расписание
  экспорта и прямой доступ к SQL-базе (структурированным таблицам данных) не подтверждены.
  Не делать из этого вывод «API нет». Авторизованный кабинет ещё не проверен.

### Wipon

- [Экспорт номенклатуры](https://docs.wipon.kz/docs/wipon-web/goods/nomenclature/addit-funcs/export/):
  меню ⋮ → экспорт → скачивание Excel через уведомления. Фильтры: склад, категория,
  тип, все товары/только в наличии. Статья не перечисляет колонки самого файла.
- [Импорт](https://docs.wipon.kz/docs/wipon-web/goods/nomenclature/addit-funcs/import/)
  документирует название, единицу, продажную цену, штрихкод; для режима с остатками
  также количество и закупочную цену. Это поля импорта, не гарантия состава экспорта.
- [Система учёта](https://wipon.kz/products/accounting/) проверена живым браузером:
  семидневное бесплатное тестирование, кнопка «Оставить заявку»; учётный кабинет
  `https://console.wipon.kz/login` требует вход, есть ссылка регистрации.
- `https://app.kassa.wipon.kz/` проверена: гостевой демонстрационный вход работает,
  открылся экран продаж ИП «ТЕСТ». Была видимая ошибка идентификатора; касса не
  доказывает полноценную работу учётной консоли или возможность экспортировать
  каталог. Чеки не создавались, товары не изменялись, регистрация не выполнялась.
- [Сторонние интеграции](https://docs.wipon.kz/docs/wipon-collabs/software/intro/)
  описаны как индивидуальные и платные. Это ограничение документированного пути,
  не доказательство отсутствия иных возможностей владельца кабинета.
- Найденные в документах ключи НКТ (Национального каталога товаров) относятся
  к обмену Wipon с НКТ, не к получению каталога Wipon нашим сайтом.
  Открытый внешний API каталога, автоматический экспорт и SQL-выгрузка не подтверждены.

### X2 POS

- Найден [официальный продукт X2 POS](https://x2pos.com/), компания X2 Retail,
  Казахстан. Вероятный кандидат для названия «2X POS» из опроса, но окончательно
  подтвердить по программе двух магазинов, не считать совпадение установленным.
- [Возможности](https://x2pos.com/ru/landing/features) прямо заявляют наличие API
  для интеграции с другими сервисами. Публичные методы чтения товаров/остатков,
  порядок выдачи ключа, права и условия доступа не найдены; API не проверялся.
- [Отчёты](https://x2pos.com/ru/otchety-magazina) выгружаются в Excel, включая
  складские отчёты. Точные колонки и полный экспорт справочника со штрихкодами
  не подтверждены. Импорт из Excel не считать доказательством полного экспорта.
- [Тарифная страница](https://x2pos.com/ru/landing/pricing) рекламирует полный
  демодоступ на 7 дней через форму. Поисковая копия `https://x2pos.com/user/register`
  показывает форму самостоятельной регистрации и 7-дневный период, но живая
  страница при проверке предлагает заявку на подключение компании.
  Живое наблюдение приоритетнее: самостоятельную регистрацию обещать нельзя.
- SQL-выгрузка, локальная схема хранения и расписание экспорта не установлены.

## Следующий ограниченный этап без переговоров

1. Первый магазин использует UMAG (подтверждено владельцем). Получить разрешённый
   доступ к его кабинету либо пробному окружению. Не создавать аккаунт с выдуманными данными.
2. Проверить настройки внешнего обмена/ключей и сделать одну выгрузку полного
   ассортимента, включая нулевые остатки. Проверить реальные колонки и типы,
   сохранность строк штрихкодов и разделение складов. Точные остатки не публиковать.
3. Выбрать путь: доступный внешний API → штатный регулярный экспорт → локальный
   помощник или расширение браузера, автоматизирующее разрешённую выгрузку.
   Последний путь технически возможен как отдельное предложение, но зависит от
   входа/сессии, работающего компьютера и устойчивости интерфейса. Пока не разработан.
   Видимые внутренние запросы не объявлять стабильным поддерживаемым API.
4. Проверить изменение цены/остатка, добавление/удаление, потерю связи, повтор,
   перезапуск и задержку обновления. Использовать общую основу Körset, не писать
   всё заново и не запускать прежние миграции повторно.
5. Ручная таблица — только первоначальный перенос/резерв. Импорт в рабочую базу,
   схема подключения и реализация автоматизации требуют отдельного согласования.

Публичная часть исследования выполнена. Обмен с реальными учётными аккаунтами,
доступ к их базе, скачивание примерного товарного файла и синхронизация с Körset
ещё не проверены. Поставщикам не отправлялись сообщения или заявки.
