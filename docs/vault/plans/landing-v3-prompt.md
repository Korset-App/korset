Полный ребилд лендинга Körset. Визуально — делай **как можно ближе к shopify.com** (главный референс), с элементами framer.com и linear.app. Старый дизайн **не смотри вообще** — только бери из него фактическое содержание (тексты, данные). Визуал — полностью новый.

## ПРОЕКТ KÖRSET

**Что:** Store-context AI assistant (mobile-first PWA) для офлайн-магазинов Казахстана. Покупатель сканирует штрихкод → получает ответ «Подходит ли?» (аллергии, Халал, диеты, КБЖУ). Модель: B2B2C, платят магазины (~15 000 тг/мес).

**Стек (ЖЕЛЕЗНО — не менять):**
- React 18 + Vite
- JavaScript (НЕ TypeScript)
- Vanilla CSS (НЕ Tailwind)
- i18n: `useI18n()` хук — ВСЕ тексты через `t('key')`, RU + KZ обязательно
- Шрифты: Advent Pro (display/headings), Inter (body)
- Акцент: `#7c3aed` (purple), sky: `#38bdf8`
- Только тёмная тема
- CSS-переменные из `src/index.css` — `var(--text)`, `var(--bg-app)`, `var(--primary)`, `var(--glass-bg)`, `var(--glass-border)` и т.д. **НЕ хардкодить** `#fff`, `#000`, `rgba(255,255,255,...)` для текста/фона/бордеров

**Адаптивность (обязательно):**
- 6 breakpoints: 360 / 480 / 768 / 1024 / 1280 / 1440
- clamp() для всех ключевых размеров
- `@media (hover: hover)` — hover только на мышке
- Height queries — компактный hero на landscape (≤680px)
- Safe-area — `env(safe-area-inset-*)`
- prefers-reduced-motion — отключать анимации
- focus-visible — accessibility
- Mobile-first

**Файлы:**
- `src/screens/LandingScreen.jsx` — ПЕРЕПИСАТЬ ПОЛНОСТЬЮ
- `src/screens/LandingScreen.css` — ПЕРЕПИСАТЬ ПОЛНОСТЬЮ
- `src/locales/ru/home.json` — обновить ключи
- `src/locales/kz/home.json` — обновить ключи (зеркально RU)
- `public/landing/` — папка для изображений (создать если нет)
- `src/index.css` — НЕ трогать, только читать CSS-переменные
